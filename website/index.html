ABSTRACT

Efficient fish feeding assessment for real-world aquaculture.

Fish feeding intensity assessment (FFIA) is important for efficient aquaculture management, but existing audio-visual systems can be computationally expensive because they process all modalities for every input.

DynaGate-FFIA addresses this problem with a lightweight gating mechanism that dynamically routes each sample to an appropriate expert. The model combines acoustic and visual information while avoiding unnecessary computation whenever a cheaper modality is sufficient.

On the AV-FFIA benchmark, DynaGate-Light reaches 96.4% test accuracy using only 5.19 GFLOPs.

MOTIVATION

Why not use expensive multimodal fusion for every sample?

01

Audio

Feeding sounds can provide useful information even when visual conditions are poor.

Pump noise Bubble noise Water flow
02

Video

Visual observations reveal fish aggregation and surface activity.

Low light Turbidity Occlusion
03

Static Fusion

Static multimodal models execute expensive computation even when one modality is already sufficient.

High compute Fixed pipeline Noise-sensitive
The key idea: the best modality can depend on the input.

ROBUSTNESS

The gate adapts when a sensor becomes unreliable.

Dynamic routing helps isolate corrupted modalities instead of forcing noisy information into a static multimodal fusion pipeline.
